Ready. Enter the WSS URL for SIP signaling then press Connect. Important note: browsers do not easily allow sending real SIP OPTIONS over raw-text WebSocket in all cases, but this tool sends the keepalive text as-is and monitors server responses and close codes (1000/1005/1006/1011) to see whether drops happen despite the pings or the pings themselves fail.

Code 1006 = abnormal closure (no close frame) — usually network or a timeout from a proxy like Railway. Code 1005 = no status code sent. Code 1000 = normal, expected closure. Compare drop timings here with 603 timings to see if the two are related.
