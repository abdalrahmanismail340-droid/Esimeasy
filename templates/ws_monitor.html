مراقب اتصال WebSocket (SIP Signaling)

يسجل وقت الاتصال، أكواد القطع، ونبضات keepalive لتشخيص انقطاع الإشارة.

الحالة: غير متصل مدة الاتصال الحالي: 00:00 عدد الانقطاعات: 0 آخر كود إغلاق: —
جاهز. أدخل رابط الـ WSS الخاص بالـ SIP signaling ثم اضغط اتصال. ملاحظة مهمة: المتصفحات لا تسمح بإرسال SIP OPTIONS حقيقي عبر WebSocket نص خام بسهولة في كل الحالات، لكن هذه الأداة ترسل نص الـ keepalive كما هو وتراقب استجابة السيرفر وأكواد القطع (1000/1005/1006/1011) لمعرفة هل الانقطاع يحدث رغم النبضات أم أن النبضات نفسها تفشل.

كود 1006 = إغلاق غير طبيعي (لا close frame) — عادة بسبب الشبكة أو timeout من وسيط مثل Railway. كود 1005 = لا يوجد status code مُرسل. كود 1000 = إغلاق طبيعي ومتوقع. قارن توقيت الانقطاعات هنا مع توقيت 603 لمعرفة إن كان الطرفان مرتبطين.
